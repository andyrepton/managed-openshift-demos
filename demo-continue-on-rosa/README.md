# Continue AI Code Assistant on ROSA

> **Status: Work in Progress** -- This demo is under active development and is not yet ready for use.

This demo will cover deploying the [Continue](https://continue.dev) AI code assistant on a ROSA cluster, connecting it to an in-cluster LLM for private, self-hosted code completion and chat.

## Planned Content

* Deploying a model-serving backend on ROSA (e.g., via OpenShift AI).
* Configuring Continue in OpenShift Dev Spaces or a local IDE to use the in-cluster endpoint.
* End-to-end code completion workflow.

For a related setup that includes Continue configuration alongside GitLab Duo, see [GitLab Duo on ROSA](../demo-gitlab-duo-on-rosa).
