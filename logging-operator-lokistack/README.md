# OpenShift Logging operator for LokiStack

This folder installs the Red Hat OpenShift Logging operator (stable channel)
into the `openshift-logging` namespace with an OperatorGroup and a Subscription,
as a building block for LokiStack logging. The full walkthrough, covering the
Loki Operator, S3 storage and LokiStack configuration, is published on the Red
Hat Cloud Experts site.

I ended up writing a how-to do this in the MOBB docs here: https://cloud.redhat.com/experts/o11y/openshift-logging-lokistack/
